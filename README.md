
The Walking Zombie 2 Broom Weapon Mod (v1.0)

The Walking Zombie 2 Broom Weapon Mod is a custom BepInEx 5 plugin for the PC version of The Walking Zombie 2 that introduces a brand-new, high-reach melee weapon to your arsenal. Built with C# and Harmony, this mod injects a standalone Broom weapon directly into your save without replacing or breaking existing melee items like the Pitchfork, Baseball Bat, or Crowbar.

Weapon Stats & Overview

Damage: 57 per hit
Attack Cooldown: 0.45 seconds
Reach Multiplier: 2x Extended Reach (ideal for keeping zombie hordes at a safe distance)
In-Game Value: 137,984 Silver
Compatibility: Works alongside the Pitchfork and all base-game weapons

Key Features

Non-Destructive Weapon Injection: Adds the Broom as an independent inventory item rather than overwriting vanilla weapons or textures.
Extended Crowd-Control Range: With double the standard melee reach and a fast 0.45s swing cooldown, the Broom lets you clear walkers before they enter grab range.
Instant Inventory Hotkey: Spawn the weapon anytime during gameplay with a single keypress (F8), making it easy to test or use on existing saves.
Custom UI Icon: Includes a dedicated inventory icon (BroomWeaponMod) bundled in the plugin folder.

Requirements

Game Version: The Walking Zombie 2 (PC / Steam, 64-bit)
Mod Loader: BepInEx 5 (x64) installed and initialized (run the game once after installing BepInEx so the plugins folder is generated).

How to Install

1. Install BepInEx 5 (x64): Download the 64-bit release of BepInEx 5 and extract its contents into your main The Walking Zombie 2 installation directory (where TheWalkingZombie2.exe is located). Launch the game once to generate the BepInEx\plugins\ folder, then close it.
2. Download the Mod: Click Download BroomWeaponMod.zip (v1.0) on this page.
3. Extract to Plugins Folder: Extract BroomWeaponMod.zip directly into your main The Walking Zombie 2 folder. Verify that BroomWeaponMod.dll and the weapon icon file are located inside The Walking Zombie 2\BepInEx\plugins\BroomWeaponMod\.
4. Spawn the Broom In-Game: Launch The Walking Zombie 2, load your save file, and press F8 on your keyboard to add the Broom directly to your inventory.

Troubleshooting & FAQ

Pressing F8 does nothing: Make sure you installed the x64 version of BepInEx 5 (not x86 or BepInEx 6) and that you are actively loaded into a save file rather than sitting on the main menu.
Folder structure issues: Double-check that you didn't accidentally create a nested folder (such as BepInEx\plugins\BroomWeaponMod\BroomWeaponMod\). The .dll file should sit directly inside BepInEx\plugins\BroomWeaponMod\.
Safe to remove? Yes—because this mod uses Harmony patches at runtime, removing the BroomWeaponMod folder cleanly uninstalls the plugin.
