Key Features

  • Non-Destructive Weapon Injection: Adds the Broom as an independent item rather than overwriting vanilla weapons or textures.
  • Extended Crowd-Control Range: With extended melee reach and a fast 0.45s swing cooldown, the Broom lets you clear walkers before they enter grab range.
  • Trader Availability: Integrates naturally into gameplay—purchase the Broom directly from in-game traders as you progress through settlements.
  • Custom UI Icon: Includes a dedicated inventory icon bundled directly in the plugin folder.

How to Install

  1. Install BepInEx 5 (x64) into your The Walking Zombie 2 game folder and run the game once to generate the plugins folder.
  2. Extract BroomWeaponMod.zip directly into your main The Walking Zombie 2 folder so BroomWeaponMod.dll and the icon land inside BepInEx\plugins\BroomWeaponMod\.
  3. Launch the game, load your save, and purchase the Broom from in-game traders (spawn chance by settlement):
    • Woodlands: 1%
    • Springfield: 2%
    • City of the Sun: 3%
    • Northtown: 4%

Troubleshooting & FAQ

Broom isn't showing up at traders
Because the spawn chance is low (1%–4% depending on the settlement), it may take a few trader inventory refreshes to appear. Also, double-check that you installed the x64 version of BepInEx 5 (not x86 or BepInEx 6).
Folder structure issues
Make sure you didn't accidentally create a nested folder (such as BepInEx\plugins\BroomWeaponMod\BroomWeaponMod). The .dll file should sit directly inside BepInEx\plugins\BroomWeaponMod\.
Is it safe to remove?
Yes—because this mod uses Harmony patches at runtime, removing the BroomWeaponMod folder cleanly uninstalls the plugin.
